# otp.ShowEpList

### ``class ShowEpList(, level_of_detail='per_ep', show_documentation=False, symbol=None, tick_type=None, start=utils.adaptive, end=utils.adaptive, query_parameters=None, **kwargs)``

Bases: ``Source``

Shows available event processors from all tick servers accessible from the process
(it could be a client process, or could be a tick server, depending on where a queried symbol resides)
where the query containing this event processor is executed.

* **Parameters:**
  * **level_of_detail** (*str*) – Specifies the level of detail to show.
    Supported values are `per_ep_parameter` and `per_ep` (default).
  * **show_documentation** (*bool*) – When set to True, field **DESCRIPTION** will be added,
    with the contents of the documentation for this EP saved in it.
    Can only be set to True if `level_of_detail` is `per_ep`.
    Default value is False.
  * **symbol** (*str*) – Bound symbol on the node of the graph.
    Not set by default – the value from ``otp.run`` will be used.
  * **tick_type** (*str*) – Tick type set on the node of the graph.
    Not set by default.
  * **start** (``datetime.datetime``, ``otp.datetime``) – Time interval from which the data should be taken.
    Not set by default – the values from ``otp.run`` will be used.
  * **end** (``datetime.datetime``, ``otp.datetime``) – Time interval from which the data should be taken.
    Not set by default – the values from ``otp.run`` will be used.
  * **query_parameters** (``otp.QueryParameters``) – Additional query properties to be set in the resulting .otq file.
    They will be used if they are not overridden by other parameters or in ``otp.run``.
