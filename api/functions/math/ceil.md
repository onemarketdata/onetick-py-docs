# otp.math.ceil

### ``ceil(value)``

Returns a float value representing the smallest number that is greater than or equal to the `value`.

* **Parameters:**
  **value** (int, float, ``Operation``, ``Column``)
* **Return type:**
  ``Operation``

#### NOTE
Rounding ``otp.nan`` returns NaN
and rounding ``otp.inf`` returns Infinity.
