# otp.math.floor

### ``floor(value)``

Returns a float value representing the largest number that is less than or equal to the `value`.

* **Parameters:**
  **value** (int, float, ``Operation``, ``Column``)
* **Return type:**
  ``Operation``

#### NOTE
Rounding ``otp.nan`` returns NaN
and rounding ``otp.inf`` returns Infinity.
