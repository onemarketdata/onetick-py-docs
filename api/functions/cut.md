# otp.cut

### ``cut(column, bins, labels=None)``

Bin values into discrete intervals (mimics `pandas.cut`).

* **Parameters:**
  * **column** (``Column``) – Column with numeric data used to build bins.
  * **bins** (*int* *or* *list* **[*float* *]*) – 

    When list[float] - defines the bin edges.
